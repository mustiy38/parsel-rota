# Kayseri Parsel Rota

Kayseri İl Tarım ve Orman Müdürlüğü saha ekipleri için parsel yol tarifi aracı.

- İlçe, mahalle, ada ve parsel bilgisiyle parselin konumu ve sınırları TKGM Parsel Sorgu servisinden alınır.
- Parseller harita üzerinde gösterilir, en kısa ziyaret sırasına dizilir.
- Google Maps ile sıralı yol tarifi başlatılır.
- Excel listesi yüklenebilir, konumlar toplu sorgulanır, sonuç Excel'e aktarılır.

Tek dosyalık bir web sayfasıdır (`index.html`); GitHub Pages üzerinde yayınlanır. TKGM servisi tarayıcıdan doğrudan çağrılır; TKGM'nin günlük sorgu limiti geçerlidir, limit dolduğunda konum elle girilebilir.

Sunulan bilgiler TKGM'nin uyarısı gereği resmi ve ticari amaçla kullanılamaz; konumlar yaklaşıktır.
